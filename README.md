## Projetos em destaque

### [FinLedger](https://github.com/AronBastos/Findledger) · C# .NET 9 · PostgreSQL · React
API de ledger financeiro com os padrões que fintechs e bancos usam: transações ACID, concorrência otimista (`xmin`), `SELECT FOR UPDATE`, audit log por interceptor, soft delete, índices parciais e compostos, e CQRS (EF Core na escrita, Dapper com window functions na leitura). Clean Architecture + MediatR.

### [Macro Brasil](https://github.com/AronBastos/macro-brasil) · Python · PySide6 · SQLite
App desktop para Windows que reúne séries do BCB (SGS, Focus) e do IBGE (SIDRA), com transformações, desfazer/refazer, projetos `.macro` que abrem offline e análise de surpresa do IPCA contra o Focus. Domínio isolado e **verificado por teste de arquitetura**, decisões técnicas registradas, instalador de 35 MB.

### [ImovelRadar](https://github.com/AronBastos/Imovel-Radar) · C# .NET 10 · PostgreSQL · Blazor
Coletor headless de aluguéis na Grande Vitória que normaliza tudo em **custo mensal total** (aluguel + condomínio + IPTU mensalizado), guarda o histórico de preços e exibe os dados num dashboard Blazor. Portais plugáveis por uma interface (`IListingSource`).

### [Gurgel E-commerce](https://github.com/AronBastos/gurgel-ecommerce) · Java 17 · Spring Boot 3 · Angular 20
E-commerce full-stack com carrinho, checkout com baixa de estoque e preço congelado no pedido, Swagger, tratamento de erros padronizado, Docker e CI no GitHub Actions.
